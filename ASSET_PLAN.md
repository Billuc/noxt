# Asset Link Plan

## Goal
Create a function similar to the `link()` function generated in `generateLinkUtils` (`build.ts`), but for generating links to static assets (images, fonts, etc.). This replaces the current `getAssetRoutes`/`addAssetRoute` pattern which relies on runtime registration during page generation, making asset discovery explicit and build-time.

---

## Steps

### 1. Create `getAssetId` helper — `src/core/rendering.ts`
**Why:** Derive a public URL path from an asset's path relative to the `assets/` directory, mirroring `getRouteName` for pages.

```
export function getAssetId(pathFromAssets: string): string
```

- Normalize backslashes to forward slashes.
- Return `"/" + normalizedPath` (e.g., `"images/logo.png"` → `"/images/logo.png"`).
- No special handling for `index.*` (unlike pages, assets keep their filename).

Export it from `index.ts`.

### 2. Create `discoverAssets` — `src/shell/build.ts`
**Signature:**
```
export async function discoverAssets(): Promise<[string, RelativePath][]>
```

**Implementation:**
- Call `getFilesMatchingGlob` with pattern `"**/*"` rooted at `path.resolve("assets")`.
- Map each `RelativePath` to `[getAssetId(file.fromRoot), file]`.
- This gives callers both the public URL and the filesystem path, consistent with the return type of `discoverRouteFiles` (`[string, RelativePath][]`).

Export from `index.ts`.

### 3. Create `generateAssetUtilsCode` — `src/core/code_generator.ts`
**Signature:**
```
export function generateAssetUtilsCode(assetIds: string[]): string
```

**Generated code (pseudocode):**
```ts
// Auto-generated by noxt
type AssetId = "/images/logo.png" | "/fonts/inter.woff2" | ...;

function asset(id: AssetId): string {
  return id;
}

export { asset, type AssetId };
```

- `AssetId` is a union of all asset public URLs (same pattern as `RouteId` in `generateLinkUtilsCode`).
- Currently assets are served at the same path under `dist/`, so `asset()` simply returns the ID. If path translation is needed later (e.g., content hashing), the function body can be updated in one place.

Export from `index.ts`.

### 4. Rename `generateLinkUtils` → `generateUtils` — `src/shell/build.ts`
- Rename the function.
- Update all callers:
  - `build()` in `build.ts`
  - `tests/fixtures/build.ts`
  - `index.ts` exports
- Update references in `docs/` if the public API is documented.

### 5. Update `generateUtils` signature — `src/shell/build.ts`
```
export async function generateUtils(
  pageFiles: [string, RelativePath][],
  assetFiles: [string, RelativePath][],
): Promise<void>
```

**New logic:**
1. Compute route names from `pageFiles` (unchanged).
2. Call `generateLinkUtilsCode(routeNames)` → generates `link()` code.
3. Extract asset IDs from `assetFiles`, call `generateAssetUtilsCode(assetIds)` → generates `asset()` code.
4. Concatenate both code strings.
5. Write combined code to `.cache/utils.ts`.

**Caller (`build()` and `tests/fixtures/build.ts`) must now:**
1. Call `discoverAssets()` separately.
2. Pass the result as the second argument to `generateUtils`.

**Output of `.cache/utils.ts`:**
```ts
// Auto-generated by noxt
type RouteId = "/" | "/about" | "/blog/post";
type QueryParams = Record<string, string | number | boolean>;

function link(routeId: RouteId, query?: QueryParams): string {
  if (!query) return routeId;
  const entries = Object.entries(query);
  if (entries.length === 0) return routeId;
  const params = new URLSearchParams();
  for (const [k, v] of entries) {
    params.append(k, String(v));
  }
  return routeId + "?" + params.toString();
}

type AssetId = "/images/logo.png" | "/fonts/inter.woff2";

function asset(id: AssetId): string {
  return id;
}

export { link, asset, type RouteId, type AssetId };
```

### 6. Remove `getAssetRoutes` / `addAssetRoute` — `src/core/registry.ts`
- Delete `assetRoutes` map, `addAssetRoute()`, and `getAssetRoutes()`.
- Remove callers of `addAssetRoute` in `src/shell/pages.tsx:17`.
- Remove callers of `getAssetRoutes` in `build.ts` (`generateRouteMap` and `generateStaticPages`).
- If assets are still needed in the route map/static manifest, switch those loops to use the result of `discoverAssets()`.
